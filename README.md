# Lens — AI-Generated Image Detector

A single-page web app that estimates whether a portrait was photographed or generated by a GAN.
FastAPI backend + React frontend. One command to run.

---

## Requirements

| Tool    | Version |
|---------|---------|
| Python  | 3.9+    |
| Node.js | 18+     |
| npm     | 9+      |

---

## Setup

### 1. Python environment

```bash
# From the repo root
python -m venv venv

# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate

pip install -r app/backend/requirements.txt
```

### 2. Node environment

```bash
cd app/frontend
npm install
npm run build       # outputs to app/backend/static/
cd ../..
```

### 3. Sample images (optional)

Drop up to 6 face images named `1.jpg` through `6.jpg` into the `samples/`
folder at the repo root. The "Or try an example" row will show them.

---

## Run (production mode)

```bash
# From the repo root — builds must already exist (step 2 above)
python app/backend/server.py
```

Open **http://localhost:8000**.

---

## Development (hot-reload frontend)

Start the backend in one terminal:

```bash
python app/backend/server.py
```

Start the Vite dev server in a second terminal:

```bash
cd app/frontend
npm run dev
```

Open **http://localhost:5173**. API calls are proxied to port 8000 automatically.

## Model

`models/resnet50_finetuned_best.pth` — do not retrain, re-export, or modify.
Weights are not distributed with this repository.
